**Aesthetic:** Cinematic Dark Editorial Minimal with Strict Zero-Radius Geometry

---

## 1. Visual Paradigm & Core Rules

1. **Strict Zero Border-Radius (`0px`):** Every element terminates at an absolute 90-degree right angle (buttons, cards, tags, inputs, modals). Chamfering (45-degree 4px cut-corners) is permitted exclusively on GPU telemetry indicator chips.
2. **Hairline Vector Grids:** Depth and visual structure are defined strictly by continuous 1px hairline vector dividers (`#21262D`) and surface tonal variation, never blurry drop shadows.
3. **Luminescent Telemetry Accents:** High-voltage Electric Cyan (`#00F2FE`) and Phosphor Mint (`#0AE8B7`) pierce deep obsidian surfaces solely for active computation vectors, verified safe nodes, and high-priority metrics.

## 3. Typography Hierarchy

- **Editorial Headings (`Newsreader`):** High-culture serif pairing for dossier narratives, research titles, and executive section summaries (`font-weight: 400`, `500`).
- **Analytical Engine (`Geist`):** Cold mechanical sans-serif for high-density tables, UI buttons, and data readouts.
- **Micro-Metric Telemetry (`Geist Mono` / `label-code`):** Uppercase, letter-spaced (`0.08em`) font for CUDA coordinates, latency timers, and graph memory counts.
