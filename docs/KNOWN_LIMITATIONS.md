# Known Limitations — FraudGraph Intelligence (FGI)

## 1. Hardware & CUDA Compilation Limitations

1. **Absence of Local NVCC & MSVC Compiler:**
   - The local host environment contains an NVIDIA GeForce MX450 GPU (Turing, Compute Capability 7.5, Driver 581.83), but lacks the local NVIDIA CUDA Toolkit compiler (`nvcc`) and Microsoft Visual C++ Build Tools (`cl.exe`).
   - Consequently, native compilation of `.cu` CUDA kernels cannot occur directly within the Windows host environment without installing these multi-gigabyte build suites.
   - **Mitigation:** The system incorporates a Google Colab GPU cloud execution adapter (`backend/gpu_engine/colab_runner/`) that bundles graph CSR arrays and kernel sources, executes them on an NVIDIA cloud GPU (T4 / A100), and returns verified, machine-readable benchmark logs and tensors to the local workspace.

2. **GPU Memory Ceiling (Local Hardware):**
   - The local MX450 provides 2048 MiB (2 GB) of dedicated VRAM. While sufficient for subgraphs up to ~100,000 nodes with $D=32$ features, full-scale financial graphs ($>1M$ nodes, high feature dimensions) will exceed local VRAM and require batch partitioning or execution on cloud instances with 16 GB+ VRAM.

---

## 2. Graph Construction & Data Constraints

1. **Anonymized Attribute Heuristics:**
   - In public benchmarks (e.g. IEEE-CIS), edges between transactions are inferred based on co-occurring payment identifiers (`card1`), shared device IDs, or temporal proximity. These edges represent strong relational proxies rather than guaranteed physical banking linkages.
2. **Dynamic Temporal Shifts:**
   - Real-world fraud patterns evolve rapidly. Static graph snapshot aggregations do not inherently model concept drift unless periodic sliding-window re-aggregation is performed.

---

## 3. Scope & Fraud Assertion Boundaries

1. **Experimental Predictions vs. Real Fraud Findings:**
   - Predicted fraud scores generated by downstream classifiers are strictly experimental outputs. In accordance with Master Directive integrity rules, no transaction prediction will be represented as a confirmed real-world fraud finding without external verification.
